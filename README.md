# CheapFlights

A responsive, static flight-discovery landing page built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. No build step or dependencies are required.

## Included

- Responsive travel landing page and destination inspiration cards
- Flight search form with round-trip/one-way selection, date validation, traveler count, nonstop preference, and swap-cities control
- Sample destination fares for visual inspiration; these are not live flight prices

## Live flight data

The search form currently provides a client-side summary only. To show real availability and bookable prices, connect it to a flight-search provider/API and implement the required server-side credentials, results UI, and booking flow. Do not put secret API keys in client-side JavaScript.
